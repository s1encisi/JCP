在Windows上新建Python 3.11.14虚拟环境，从官方PyPI安装 `requirements-demo.txt`。环境不安装PyTorch或私有模型资产。

- 18项自动化测试通过。
- `pip check` 返回 `No broken requirements found`。
- 演示不读取本地研究模型，也不依赖外部字体或JavaScript CDN。

复查命令：

```powershell
python -m unittest discover -s tests -v
python -m pip check
```

## 本机研究资产接口

修正模型目录后，本机9个代理模型和3个PPO策略均成功加载。三种工况的代理预测、策略推理接口共6次调用均返回HTTP 200，来源字段为`real`。该检查只验证接口、特征顺序和权重兼容性，不用于估计泛化误差。相关权重和预测输出未加入公开仓库。

## 本轮修复的实质问题

- 统一预测接口、界面和优化定义的As下限、Cu/As上限，补齐电流密度及单槽电压检查。
- 正确解码PPO增量动作，保留串联两单元变量，避免把归一化动作当成绝对电流。
- 修复实验记录字段映射、伪造运行时间、空历史自动填入示例、固定内容导出。
- 区分完成与失败状态，优化结果真正进入表格、投影、主页和下载。
- 去除隐式模拟模型回退、任意文件静态下载、任意数据库连接与SQL入口。
- 隔离运行数据目录，修复两个研究脚本的个人电脑绝对路径。
- 保留此前的主页大字号和高像素密度Canvas绘制改动。
